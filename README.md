# Craft AI Web (ai.lmk.one)

WebAssembly deployment of **Craft AI Integrations** (`storytold/craft-ai-integrations`).

## Features
- Unified AI Hub for the entire `*craft` suite (PhotoCraft, VectorCraft, FilmCraft, FigCraft, WordCraft, SolidCraft, LightCraft, SoundCraft, DeckCraft).
- Full support for Light, Dark, and Sepia themes matching `pl.lmk.one` / `craft.lmk.one`.
- URL parameter routing: `?tool=`, `?model=`, `?provider=`, `?prompt=`, `?app=`, `?theme=`, `?lang=`.
- Selective execution: SAM 3 Subject Selection, Background Removal (Matte), Image Generation (FLUX 1.1 Pro, DALL-E 3, Gemini Imagen 3), Generative Fill, Video Generation (Seedance), Outpaint, Text Assistant.
- Local ComfyUI connector + Cloud API keys (OpenAI, Gemini, BFL, BytePlus).
- Zero-leakage privacy: all keys and requests remain local to the browser (LocalStorage).
- Native Polish (PL) and English (EN) localization.

Live: [https://ai.lmk.one/](https://ai.lmk.one/)
